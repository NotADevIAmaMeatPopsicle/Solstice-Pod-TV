Full Clean Install (or Resume)

Flashes boot, recovery, and system, formats userdata and cache as ext4, applies TV defaults, installs APKs from your APKs folder, and verifies the Pod. If the Pod is already booted in Android, skips flashing and resumes provisioning. Never touches persist, modem, or bt_firmware.


Upgrade OS (Keep Data & Apps)

Flashes updated boot, recovery, and system images without wiping userdata. If the Pod is booted in Android, automatically reboots it to fastboot first, flashes, and verifies the new build.

Backup Partitions (ADB Root)

Saves raw partition images and a verified SHA-256 manifest into a timestamped folder per Pod serial. Requires a booted Pod with Rooted debugging enabled.

Restore from Backup (Fastboot)

Verifies SHA-256 hashes before flashing. Sensitive factory partitions (persist, modem, bluetooth) are skipped by default to prevent overwriting another Pod's MAC addresses.
